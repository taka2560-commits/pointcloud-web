--------------------------------------------------------------------------------
1. プロジェクト概要
--------------------------------------------------------------------------------
・プロダクト名: E57点群ノイズ処理・断面スライサー ツール (E57_PointCloud_Tool)
・対象データ  : 3Dレーザースキャナーから取得された大容量E57形式 (.e57) 点群データ
・主要機能    :
  - 数千〜数千万点の点群の超高速OpenGL 3D表示（GPU VBOキャッシュ）
  - 統計的外れ値(SOR)、半径外れ値(ROR)、孤立クラスタ(DBSCAN)、大まかな孤立塊除去
  - レイヤー管理（通常点群／ノイズ点群の二層構造、ノイズのピンポイント復元）
  - XYZ 3軸断面スライサー & 2点ピックによる斜め壁アラインメントスライス
  - E57完全ロスレス保持保存（倍精度Float/ScaledInteger、属性、ポーズ、メタデータ）
  - 現場別実践レシピ（8種類）のワンクリックUIセレクター
  - 取り込み座標系変換（数学座標系、測量座標系X/Y入替、Y-up、Z反転）
  - システム履歴ロギング（UIからログフォルダをワンクリック表示）

2. 開発時の厳守ルール（最重要）
--------------------------------------------------------------------------------
[ルール1] 日本語出力の厳守
  ・すべての会話、ドキュメント、実装計画書、コード内コメント、コミットメッセージは
    必ずすべて「日本語」で記述してください。

[ルール2] E57完全ロスレス保持の原則
  ・Float32へ安易にダウンキャストして保存しないこと（測量精度が損なわれます）。
  ・元のE57のScaledInteger（スケール・オフセット）、RGBカラー、反射強度、法線、
    スキャナーポーズ行列を1ビットも欠落させずに保存すること (core/e57_io.py 参照)。
  ・保存時は必ず「一時ファイル(.tmp)書き出し＋アトミック置換」でファイル破損を防ぐこと。

[ルール3] UIフリーズ・メモリ枯渇の防止
  ・数千万点の点群に対して O(N^2) の距離計算や全点DBSCANを実行しないこと。
  ・必ず「適応型ボクセルグリッド化」「代表点安全リミッター(REPRESENTATIVE_POINT_LIMIT=20万点)」を介すこと。
  ・読み込み・フィルタ・座標変換・保存などの重い処理は、絶対にメインUIスレッドで
    同期実行せず、gui/worker_thread.py (QThread) に逃がすこと。
    専用ワーカーが無い処理は汎用 FunctionWorker + MainWindow._run_in_background() を使う。
  ・ワーカーの停止は cancel() -> wait() の協調的中断。QThread.terminate() は最後の手段。
  ・フィルタが「全点除去」になる場合は全点保持＋警告ログに倒す（全点消失事故の防止）。

[ルール5] 座標系変換した点群の保存は「元の座標系・元のスケール」で
  ・取り込み時の座標系変換は表示・編集用。保存時は FileSaveWorker が自動で元の座標系へ
    逆変換してからビット完全一致で書き戻す（tests/test_coord_roundtrip.py で検証）。

[ルール7] UI は新UI（modern）と従来UI（classic）を両立させる（詳細は AI_HANDOVER.md §2-⑦）
  ・新UIは gui/modern_ui.py が従来UIに後付けする方式。従来UIのコードと DARK_THEME_QSS は削除・変更しない。
  ・新UIの配色はテーマ（dark / kiseki）としてトークンだけを分け、モーションは gui/motion.py に集約する（詳細は docs/DESIGN_STYLE_PLAN.md §9・§10）。
  ・新UIの色・文字サイズ・角丸は gui/design_tokens.py でのみ変更。インライン QSS と絵文字ラベルは追加しない。
  ・不具合時は 起動引数 --classic-ui / 環境変数 E57_UI_MODE=classic / 設定「UIスタイル」で改修前に戻せる。
  ・改修直前の main には Git タグ before-ui-redesign-2026-10-31 を付与済み。

[ルール6] 複数AIでの並行開発（詳細は AGENTS.md）
  ・元AIは「点群マイツール」フォルダ(main)、Claude は「点群マイツール-claude」worktree(claude/*)で作業。
  ・他方のフォルダを直接編集しない。取り込みは git マージのみ。作業終了時は必ず全ファイルをコミット。
  ・gui/main_window.py, gui/gl_viewer.py は元AIの担当。Claude は最小限・まとめて・マージ直後に変更。

[ルール4] 座標系の定義（数学系と測量系の違い）
  ・3Dビューアは「数学座標系（デカルト右手系・Z-up）」で実装されています。
    画面右=+X, 画面上=+Y, 画面手前=+Z（上面視点で右X・上Y）。
  ・日本の公共測量（平面直角座標系）は「X=北(縦), Y=東(横)」のため縦横が逆です。
    ビューアの軸を改造せず、取り込み時の「測量座標系→数学系(X/Y入替)」で対応すること。

3. 主要モジュールと役割
--------------------------------------------------------------------------------
main.py               : アプリ起動、高DPI設定、ロガー初期化、未捕捉例外フック
quality_gate.py       : 全5段階の自動回帰テストスクリプト（最重要CI。--quick で GUI 無し、--fix-eol で .bat 改行修復）
AGENTS.md / CLAUDE.md : 複数AI並行開発の共通ルール（作業場所・担当ファイル・マージ手順）
QA_REPORT_2026-10-31.md: 総合品質管理チェック報告書（欠陥一覧・修正状況・backlog）
core/e57_io.py        : E57完全ロスレス入出力エンジン
core/filters.py       : ノイズ除去・間引きアルゴリズム（SOR, ROR, DBSCAN, 孤立塊等）
core/processor.py     : FilterConfig、座標系変換関数、パイプライン実行
core/logger.py        : システム履歴ロガー（日別UTF-8出力、クラッシュダンプ）
gui/gl_viewer.py      : OpenGL 3D点群ビューア（VBO、視点ギズモ、手動選択、スライス）
gui/main_window.py    : メイン画面UI、リボンバー、レイヤー管理、レシピセレクター
gui/worker_thread.py  : 非同期バックグラウンドワーカー（QThread、汎用 FunctionWorker）
gui/layer_history.py  : 差分ベースのレイヤー Undo/Redo 履歴（全点コピーをしない）
gui/progress_dialog.py: キャンセル対応モーダル進捗ダイアログ

4. テストとビルドの手順
--------------------------------------------------------------------------------
【テスト実行】
  ・「品質チェック実行.bat」 を実行するか、コマンドラインで以下を実行：
      python -X utf8 quality_gate.py          （全5ゲート。コミット時にも pre-commit フックで自動実行）
      python -X utf8 quality_gate.py --quick  （Gate 1/3/5 のみ。GUIを開かない作業中の確認用）
  ・全5ゲート（構文/DOM整合、ビューア不変条件、境界値ファジング、実機GUIシナリオ、
    unittest スイート 66件）がすべてPASSすることを確認してください。

【スタンドアロンEXEのビルド】
  ・「EXE配布パッケージ作成.bat」 をダブルクリックしてください。
  ・E57_PointCloud_Tool.spec から PyInstaller ビルド → マニュアル/README を EXE と同じ階層へコピー
    → 旧ZIPを dist/archive へ退避 → 最新ZIP（dist/E57_PointCloud_Tool_Dist.zip）の生成が行われます。
  ・pyinstaller main.py を直接実行しないこと（spec が上書きされ同梱設定が消える）。
  ・依存パッケージを追加したら requirements-desktop.txt・起動.bat の import 検査・AI_HANDOVER.md §3 を
    同じコミットで更新すること。

--------------------------------------------------------------------------------
5. 過去の重要トラブルと対策（教訓）
--------------------------------------------------------------------------------
1. クラスタフィルタによるPCフリーズ:
   -> 代表点安全リミッターと適応型ボクセルDBSCANを導入して解決。
2. 大まかなノイズ処理での解析停止:
   -> 1Dビットパック超高速ボクセル化を導入し、完全非同期スレッド化して解決。
3. E57保存時の座標丸め・属性欠落:
   -> ScaledInteger復元ロジックと一時ファイルアトミック書き出しで解決。
4. 高さスライダードラッグ時の描画遅延:
   -> ドラッグ中はカラーマップLUTの60fps高速参照、離した時にVBO確定同期で解決。
