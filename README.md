# E57点群ノイズ処理ツール (E57 Point Cloud Noise Filter)

3Dレーザースキャナーから取得された **E57形式（.e57）の点群データ** から、浮遊ノイズや空中散乱光、外れ値を除去し、クリーンなE57点群ファイルとして再出力するデスクトップツールです。

---

## 主な特徴

- **E57完全対応**: 座標（XYZ）、RGBカラー、反射強度（Intensity）、および複数スキャン（マルチステーション）の階層構造を保持したまま安全に出力。
- **高精度ノイズ除去**:
  - **統計的外れ値除去 (SOR)**: 空中散乱光や浮遊点などの孤立ノイズを統計的手法で除去。
  - **半径ベース外れ値除去 (ROR)**: 一定半径内の近傍点密度が疎な点群を除去。
  - **距離・反射強度フィルタ**: スキャナー近傍/遠方の不要点や、黒色・鏡面反射ノイズを除去。
  - **ボクセル間引き**: データが重い場合に指定グリッド（例: 2cm）で均一に軽量化。
- **直感的な日本語3D GUI**:
  - **3Dソフト（CloudCompare等）準拠の点群ビューア**:
    - [マウス左ドラッグ]: 視点オービット回転
    - [マウス右/中ドラッグ]: 画面平行移動（パン）
    - [マウスホイール]: スムーズ拡大・縮小（ズーム）
    - [視点プリセット]: 等角(Iso)、上面(Top)、正面(Front)、側面(Side)
    - [多彩な配色]: RGBカラー、高さ(Z)グラデーション、反射強度、単色
    - [点サイズ調整]: 1〜10px
  - **手動ノイズ除去機能 (NEW)**:
    - **矩形選択モード**: 画面上をドラッグして不要な点群を四角く範囲選択（選択点は赤色ハイライト）。
    - **選択点削除 (Deleteキー)**: 選択したノイズ点をワンクリックで即座に消去。
    - **元に戻す (Ctrl+Z)**: 誤って消した点群を安全にアンドゥ復元。
    - **手動編集後の保存**: 編集したクリーンな点群をそのままE57形式で再出力。
  - ドラッグ＆ドロップによるE57読み込み対応。
  - 処理中のフリーズを防ぐ非同期マルチスレッド設計。
- **バッチ処理用CLI**: ターミナルやバッチファイルからの一括処理に対応。

## 起動方法

### 1. GUI アプリケーションの起動
```bash
python main.py
```
起動後、画面にE57ファイルをドラッグ＆ドロップし、フィルタを設定して「ノイズ処理を実行」をクリックします。

### 2. コマンドライン (CLI) による実行
```bash
# 基本実行 (SORノイズ除去を適用して自動命名保存)
python cli.py input.e57

# 出力先とパラメータを指定して実行
python cli.py input.e57 -o output_clean.e57 --sor-neighbors 20 --sor-ratio 2.0

# 半径外れ値除去 (ROR) やボクセル間引きを併用
python cli.py input.e57 -o output_clean.e57 --ror --ror-radius 0.05 --voxel-size 0.02
```

## パラメータ設定の目安

| フィルタ項目 | デフォルト値 | 設定の目安・アドバイス |
| :--- | :--- | :--- |
| **SOR: 近傍探索点数** | `20` | 通常は `15` 〜 `30` 程度。点群が密な場合は `30`〜`50` に増やすと安定します。 |
| **SOR: 標準偏差倍率** | `2.0` | **値を小さくする（例: 1.0〜1.5）と厳格に除去**されます。建築物などのエッジを削りすぎないよう、まずは `2.0` 前後から試すのがおすすめです。 |
| **ROR: 探索半径** | `0.05m` (5cm) | 点群の密度に応じて調整します。スキャン距離が離れて点間隔が広い場合は大きめに設定します。 |
| **ROR: 必要点数** | `16` | 探索半径内に含まれる最小点数。値を大きくするほどノイズ判定が厳しくなります。 |
