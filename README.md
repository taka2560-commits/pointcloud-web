# E57点群ノイズ処理ツール (E57 Point Cloud Noise Filter)

3Dレーザースキャナーから取得された **E57形式（.e57）の点群データ** から、浮遊ノイズや空中散乱光、外れ値を除去し、クリーンなE57点群ファイルとして再出力するデスクトップツールです。

---

## 主な特徴

- **E57完全対応（完全ロスレス保持）**: 座標（XYZ：倍精度 `FloatNode` / `ScaledIntegerNode` 完全維持）、RGBカラー、反射強度（Intensity）、法線、タイムスタンプ等の拡張属性、および複数スキャン（マルチステーション）構造を1ビットの劣化もなく保持したまま安全に出力。
- **高精度5段階ノイズ除去フィルタ（GUI・CLI両対応）**:
  - **統計的外れ値除去 (SOR)**: 空中散乱光や浮遊点などの孤立ノイズを統計的手法で除去。
  - **半径ベース外れ値除去 (ROR)**: 一定半径内の近傍点密度が疎な点群を除去。
  - **孤立クラスタ（浮遊小塊ノイズ）除去 (DBSCAN)**: 従来のSOR/RORでは除去しにくい、空中に浮遊する高密度な小塊ノイズ（人影の残骸・粉塵塊など）を丸ごと除去。
  - **距離・反射強度フィルタ**: スキャナー近傍/遠方の不要点や、異常な反射強度（黒色・鏡面反射ノイズ）を除去。
  - **ボクセル間引き**: データが重い場合に指定グリッド（例: 2cm）で均一に軽量化（元の実在点座標を抽出）。
- **直感的な日本語3D GUI（デスクトップ版 OpenGL VBO高速描画 ＆ Web版 Three.js）**:
  - **3Dソフト（CloudCompare等）準拠の高速点群ビューア**:
    - OpenGL VBO（GPUメモリキャッシュ）による数百万点の滑らかなカメラ操作
    - [マウス左ドラッグ]: 視点オービット回転 / [右・中ドラッグ]: 画面平行移動（パン） / [ホイール]: 拡大・縮小
    - [視点プリセット]: 等角(Iso)、上面(Top)、正面(Front)、側面(Side) / 透視投影・正射影（オルソ `[P]`）切替
    - [多彩な配色]: RGBカラー、高さ(Z)グラデーション（Turbo / Viridis / Jet）、反射強度（2%〜98%パーセンタイル自動コントラスト調整付き）、単色
  - **二層レイヤー管理（通常点群レイヤー / ノイズレイヤー）**:
    - 自動・手動で除去した点を即削除せず「ノイズレイヤー（赤色）」へ分離保持。
    - チェックボックスで通常点群とノイズ点群の表示/非表示をリアルタイム切替。
    - **選択したノイズのみ復元**: ノイズレイヤーを表示して必要な点だけを範囲選択し、ピンポイントで通常レイヤーへ復帰可能。
  - **高度な手動選択・断面クロップ機能**:
    - **3種類の選択形状**: 🔲 矩形選択 / ⭕ 円形選択 / 🔷 多角形選択（ラッソ）
    - **修飾キー＆反転**: `[Shift + 選択]` で追加選択、`[Ctrl + 選択]` で選択除外、`[I]` キーまたはボタンで選択反転。
    - **XYZ 3軸断面スライサー＆断面外クロップ**: 任意の範囲で断面表示し、「✂️ 断面ボックス外をノイズへ一括移動」で不要な周囲・天井・床面を一括トリミング。
    - **Undo (`Ctrl+Z`) / Redo (`Ctrl+Y`)**: 編集履歴の遡りとやり直しに完全対応。
    - **計測ツール `[M]`（座標の読み取り）**: 点をクリックすると、クリック位置に見えている点の原本座標 X/Y/Z を表示（12px 以内に点が無ければ拾わない。座標系変換で読み込んだときはファイル系の値も併記）、2点目で直線距離・水平距離・高低差・ΔX/ΔY/ΔZ。`[Ctrl+C]` でタブ区切りコピー（Excel / CAD に貼付可）。
    - **非同期プログレス付き保存**: 大容量E57ファイルの書き出し中もプログレスダイアログで進捗を表示し、UIフリーズを防止。

## 起動方法

### 0. 必要な環境（デスクトップ版）
- Windows 64bit、Python 3.10 以上（3.14 で動作確認）
- 依存パッケージ: `pip install -r requirements-desktop.txt`
  （numpy / scipy / pye57 / PySide6 / PyOpenGL / **open3d** / **pyquaternion**。open3d と pyquaternion は必須です）
- 動作確認済みの固定バージョンで揃える場合は `pip install -r requirements-lock.txt`

### 1. デスクトップ GUI アプリケーションの起動
```bash
python main.py
```
（または `起動.bat` をダブルクリック。`main.py` と `core/` がある開発フォルダではソースから起動し、配布ZIP内では `E57_PointCloud_Tool.exe` を起動します）

**UI スタイル（新UI / 従来UI）**: 2026-10 のデザイン改修で、作業順（①自動除去 → ②手動修正 → ③確認 → 保存）に並んだ新UI・メニューバー（Ctrl+O 開く / Ctrl+S 保存）・ステータスバー・空状態の案内が追加されました。改修前の画面に戻すには次のいずれかを使います（設定は次回起動時に適用）。
- 画面の「ヘルプ → 従来UIに戻す」または「設定 → システム → UIスタイル」
- 起動引数: `python main.py --classic-ui`（新UIへ戻すときは `--modern-ui`）
- 環境変数: `E57_UI_MODE=classic`

**1 億点超のファイル**: 読込上限（設定「読込上限」、自動は 32GB の PC で 6,000 万点）を超えるファイルは間引いて読み込み、その画面でノイズ判定をします。保存時に「全点で保存（推奨）」を選ぶと、元ファイルを全点で読み直して判定を全点へ写し、元と同じ点密度の E57 を出力します（1 億点で数分〜十数分。元ファイルは読込後に動かさないでください）。「間引いたまま保存」は読み込んだ点だけを出力します。

**座標の扱い**: 画面・計測・断面の座標は E57 の pose（スキャンの回転と平行移動）を適用した現場の座標です。保存するファイルには元の生座標と pose をそのまま書き戻します。回転を含むファイルは、全点ぶんの表示座標を別に持つためメモリ使用量が増えます（2,200 万点で約 500MB）。

**テーマとアニメーション（新UI）**: 「設定 → システム → テーマ (新UI)」で「ダーク (標準)」と「軌跡 (明るい地・黒い帯)」をその場で切り替えられます（設定は次回起動時も保持。起動引数 `--theme=kiseki`／環境変数 `E57_UI_THEME=kiseki` でも可）。押下・通知・タブ切替の短いアニメーションは「設定 → システム → アニメーション」で OFF にできます（即時反映）。

### 2. Webブラウザ版の起動
`Webアプリ起動.bat` を実行するか、ローカルHTTPサーバーから `index.html` を開きます（PLY, XYZ, PTS, CSV対応）。
バッチは `127.0.0.1:8080` にのみ待ち受けます（同一PCからのみアクセス可）。

### 開発者・AI向け
- 設計憲章・アーキテクチャ・過去の教訓: `AI_HANDOVER.md`
- 複数AI・複数開発者での並行開発ルール（作業場所・担当ファイル・マージ手順）: `AGENTS.md`
- 総合品質管理チェック報告書（欠陥一覧・修正状況・backlog）: `QA_REPORT_2026-10-31.md`
- 品質ゲート: `python -X utf8 quality_gate.py`（全5ゲート）／`--quick`（GUIを開かない軽量版）

### 3. コマンドライン (CLI) によるバッチ実行
```bash
# 基本実行 (SORノイズ除去を適用して自動命名保存)
python cli.py input.e57

# 孤立クラスタ（浮遊塊）除去や反射強度フィルタを併用
python cli.py input.e57 -o output_clean.e57 --cluster --cluster-eps 0.15 --cluster-min-points 30 --min-intensity 0.05 --max-intensity 0.95

# 半径外れ値除去 (ROR) やボクセル間引きを併用
python cli.py input.e57 -o output_clean.e57 --ror --ror-radius 0.05 --voxel-size 0.02
```

## パラメータ設定の目安

| フィルタ項目 | デフォルト値 | 設定の目安・アドバイス |
| :--- | :--- | :--- |
| **SOR: 近傍探索点数** | `20` | 通常は `15` 〜 `30` 程度。点群が密な場合は `30`〜`50` に増やすと安定します。 |
| **SOR: 標準偏差倍率** | `2.0` | **値を小さくする（例: 1.0〜1.5）と厳格に除去**されます。建築物などのエッジを削りすぎないよう、まずは `2.0` 前後から試すのがおすすめです。 |
| **ROR: 探索半径 / 必要点数** | `0.05m` / `16点` | 点群の密度に応じて調整します。スキャン距離が離れて点間隔が広い場合は半径を大きめに設定します。 |
| **クラスタ: クラスタ距離 / 最小点数** | `0.15m` / `30点` | 点同士が `0.15m` 以内で繋がっている塊のうち、構成点数が `30点` 未満の浮遊塊（ゴミや人影の断片）を丸ごと除去します。 |
