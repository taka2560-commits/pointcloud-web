# E57点群ノイズ処理ツール (E57 Point Cloud Noise Filter)

3Dレーザースキャナーで取得した **E57形式（.e57）の点群データ** から、浮遊ノイズ・空中の散乱光・外れ値を取り除き、元の精度と構成を保ったままきれいな E57 ファイルとして書き出すデスクトップツールです。

- 座標（倍精度 / ScaledInteger）・色・反射強度・法線・タイムスタンプなどの属性と、複数スキャンの構成をそのまま保って保存します（ロスレス）。
- 消した点は「ノイズレイヤー」へ移るだけで、保存するまで元のデータは変わりません。`Ctrl+Z` でいつでも戻せます。
- 1 億点を超えるファイルは間引いて読み込み、保存のときに元ファイルの全点へ判定を写せます。

---

## 使い方の流れ

1. **開く**: E57 ファイル（またはフォルダ）を画面にドラッグ＆ドロップ。`Ctrl+O` でも選べます。
2. **① 自動**: プリセット（大まか / 標準 / 細かい）を選んで「自動ノイズ処理を一括実行」。
3. **② 手動**: 残ったノイズを矩形・ブラシなどで囲んで `Del`。消しすぎは赤い点を囲んで復元。
4. **③ 確認**: ノイズレイヤーを赤で表示して、消しすぎが無いか見る。断面で細部を確かめる。
5. **保存**: 「保存 (Ctrl+S)」。右の矢印から「保存先を選んで保存」「作業の状態を保存」も選べます。

迷ったら `F1` の操作説明書、または `Ctrl+K` で機能の名前を打って探してください（ひらがなで打てます。例: だんめん、けいそく、ほぞん）。

## 起動方法

### 配布版（EXE）
`E57_PointCloud_Tool_Dist.zip` を展開し、`E57_PointCloud_Tool.exe` をダブルクリックします。Python のインストールは不要です。

### ソースから（開発フォルダ）
- Windows 64bit、Python 3.10 以上（3.14 で動作確認）
- 依存パッケージ: `pip install -r requirements-desktop.txt`
  （numpy / scipy / pye57 / PySide6 / PyOpenGL / **open3d** / **pyquaternion**。open3d と pyquaternion は必須です）
- 動作確認済みの固定バージョンで揃える場合は `pip install -r requirements-lock.txt`

```bash
python main.py
```
（または `起動.bat` をダブルクリック。`main.py` と `core/` がある開発フォルダではソースから起動し、配布 ZIP 内では EXE を起動します）

### 画面の見た目を変える
- **UI スタイル（新UI / 従来UI）**: 既定は新UI です。改修前の画面に戻すには「ヘルプ → 従来UIに戻す」または「設定 → システム → UIスタイル」（次回起動から）。起動引数 `--classic-ui` / `--modern-ui`、環境変数 `E57_UI_MODE=classic` でも切り替えられます。
- **テーマ（新UI）**: 「設定 → システム → テーマ」で「ダーク (標準)」と「軌跡 (明るい地・黒い帯)」をその場で切り替えられます。起動引数 `--theme=kiseki`、環境変数 `E57_UI_THEME=kiseki` でも指定できます。
- **アニメーション**: 押下・通知・タブ切り替えの短い動きは「設定 → システム」で切れます。

## 主な機能

### 読み込みと保存
- 単一の E57、またはフォルダ内の全 E57 を一括で読み込み（各ファイルを器械点として表示切り替え・一括保存）。
- 座標系の読み替え（数学座標系のまま、または測量座標系の X と Y を入れ替えて読む）。保存時は元の座標系へ戻して書きます。
- 画面・計測・断面の座標は、E57 の pose（スキャンの回転と平行移動）を適用した現場の座標です。保存するファイルには元の生座標と pose をそのまま書き戻します。
- 保存対象を選べます: 有効レイヤーの統合 / 表示中のみ / 特定のレイヤーのみ / ノイズのみ / 全レイヤーを分割して出力。
- 保存中はボタンが「保存中…」、終わると「保存済み」になります。保存していない編集があると右下に「未保存の変更あり」が出ます。

### 自動ノイズ除去
- **統計的外れ値除去 (SOR)**: 空中の散乱光や浮遊点などの孤立ノイズを除去。
- **半径ベース外れ値除去 (ROR)**: 近くの点が少ない点を除去。
- **孤立クラスタ除去**: 空中に浮いた小さな塊（人影の残り・粉塵の塊など）を丸ごと除去。
- **エッジ・ヒゲ除去**: 面の縁から飛び出した点や、表面のヒゲを除去。
- **距離・反射強度フィルタ**、**ボクセル間引き**。
- プリセット（大まか / 標準 / 細かい）と、現場別のレシピ 8 種（スキャン直後の粗取り / 通常の現況 / CAD 製図向けのヒゲ除去 / 壁・薄板の保護 / 通行人・看板・車両の一掃 / 軽量化の均一間引き / 樹木・植栽の粗取り / 配管・細線の保護）。
- 自動除去はフィルタ別のレイヤーに分かれ、「1つ戻る」で段階ごとに取り消せます。

### 手動の編集
- 選択ツール: 矩形 `R` / 円形 `C` / 多角形 `L` / ブラシ `B`。`Shift` で追加、`Ctrl` で除外、`I` で反転。
- 連結している塊を丸ごと選択 `G`、選択範囲の中だけ精密除去、メインの塊だけ残す。
- 「即削除」を入れると囲んだ瞬間にノイズへ移ります。「ノイズ専用 `N`」は消す作業に絞った画面です。
- 点を動かした直後は、右下の通知の「元に戻す」を押せます（`Ctrl+Z` と同じ）。

### レイヤー
- 通常の点とノイズ（赤）を分けて持ち、表示を切り替え。ノイズは囲んで復元、または全部を復元。
- レイヤーの追加・名前変更・色・表示・ロック、選択した点のレイヤー移動。
- 地面の自動抽出、主平面の自動検出（別レイヤーへ分ける）。
- 作業の状態（レイヤーの割り当て）を `.npz` で保存・読み込み。

### 断面と細部の確認
- X / Y / Z の断面スライサー（基点と厚み）、斜めの壁に沿った断面（`U` で壁の上の 2 点を指定）。
- 断面ボックスの外をノイズへ一括で移す（周囲・天井・床のトリミング）。
- **ボックス内は全点表示**: 断面の中は表示点数の上限で間引かずに描きます（上限 1,000 万点）。
- **元ファイルから全点で読み直す**: 間引いて読み込んだファイルでも、断面ボックスの中だけ元の密度で重ね描きします（表示専用）。
- **高精細表示 (LOD)**: 視点が止まるたびに、画面に入っている範囲を元ファイルの密度で重ね描きします（全体で 600 万点まで）。

### 計測
- `M` で点をクリックすると原本の座標 X/Y/Z を表示。2 点目で直線距離・水平距離・高低差・ΔX/ΔY/ΔZ。`Ctrl+C` でタブ区切りコピー（Excel / CAD に貼れます）。

### 操作を助ける機能（新UI）
- **機能を検索 `Ctrl+K`**: やりたいことの名前を打って実行。使えない機能は理由つきで表示。
- **右クリックのパレット**: その場面で使う操作だけがカーソルの横に出ます。
- **パネルの小窓**: 左パネルのグループを「別窓」で浮かせられます。左パネルを格納すると 3D 画面の左端にボタンの列が出ます。「処理状況・ログ」も別窓に出せて、窓を大きくすればそのぶん多くの行が見えます。
- **操作ガイドとヒント**: ツールを選ぶと使い方が、点群を開いたあとは次にやるとよいことが、3D 画面の右上に出ます。ヒント集は「ヘルプ → ヒント集」。
- **操作説明書 `F1`**: 使い方を作業順にまとめています。本文のリンクを押すとその機能が動きます。「ボタンと表示の見方」もここにあります。
- **ボタンの見方**: 塗りつぶし = その場の主操作、枠だけ = 補助、文字だけ = 軽い操作、赤 + ごみ箱 = 点を消す操作。押せないボタンはマウスを置くと理由が出ます。

## 1 億点を超えるファイル

- 読込上限（設定「大容量点群読込上限」。自動では 32GB の PC で約 6,000 万点）を超えるファイルは、間引いて読み込みます。ノイズの判定はその画面で行います。
- 保存のときに **「全点で保存（推奨）」** を選ぶと、元ファイルを全点で読み直して判定を全点へ写し、元と同じ点密度の E57 を出力します（1 億点で数分〜十数分）。元ファイルは少しずつ流して読むので、5 億点を超える 1 スキャンのファイルでも、保存中に増えるメモリは数 GB で済みます。
- 細部を元の密度で見たいときは、断面の「元ファイルから全点で読み直す」か「高精細表示 (LOD)」を使います。
- **ディスクの使用量**: 読み直しと LOD は、初回に元ファイルの横の `<ファイル名>.e57.cache` フォルダへ作業用データを作ります（1 点あたり 17 バイト。5.4 億点で読み直し用に約 9GB、LOD 用にさらに約 9GB）。2 回目からはここから読むので速くなります。元ファイルが変わると自動で作り直します。不要になったらフォルダごと削除して構いません。 LOD を作っている間だけ、さらに一時ファイル（5.4 億点で約 11GB）を使います。
- 回転を含むファイルは、全点ぶんの表示座標を別に持つためメモリ使用量が増えます（2,200 万点で約 500MB）。

## パラメータ設定の目安

| フィルタ項目 | デフォルト値 | 設定の目安・アドバイス |
| :--- | :--- | :--- |
| **SOR: 近傍探索点数** | `20` | 通常は `15` 〜 `30` 程度。点群が密な場合は `30`〜`50` に増やすと安定します。 |
| **SOR: 標準偏差倍率** | `2.0` | **値を小さくする（例: 1.0〜1.5）と厳格に除去**されます。建築物などのエッジを削りすぎないよう、まずは `2.0` 前後から試すのがおすすめです。 |
| **ROR: 探索半径 / 必要点数** | `0.05m` / `16点` | 点群の密度に応じて調整します。スキャン距離が離れて点間隔が広い場合は半径を大きめに設定します。 |
| **クラスタ: クラスタ距離 / 最小点数** | `0.15m` / `30点` | 点同士が `0.15m` 以内で繋がっている塊のうち、構成点数が `30点` 未満の浮遊塊（ゴミや人影の断片）を丸ごと除去します。 |

詳しくは同梱の「ノイズフィルター設定ガイド_初心者向け完全マニュアル」を参照してください。

## コマンドライン (CLI) と Web 版

```bash
# 基本実行 (SOR を適用して自動命名で保存)
python cli.py input.e57

# 孤立クラスタ除去や反射強度フィルタを併用
python cli.py input.e57 -o output_clean.e57 --cluster --cluster-eps 0.15 --cluster-min-points 30 --min-intensity 0.05 --max-intensity 0.95

# 半径外れ値除去 (ROR) やボクセル間引きを併用
python cli.py input.e57 -o output_clean.e57 --ror --ror-radius 0.05 --voxel-size 0.02
```

Web ブラウザ版は `Webアプリ起動.bat` で起動します（PLY / XYZ / PTS / CSV 対応。`127.0.0.1:8080` にのみ待ち受け）。
