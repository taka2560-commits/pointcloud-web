================================================================================
 E57 点群ノイズ処理・断面スライサー ツール フォルダ構成とご利用案内
================================================================================

【日常の利用・起動】
  1. デスクトップアプリの起動:
     -> 「起動.bat」 をダブルクリックしてください。
        （自動的にPython環境またはスタンドアロンEXEを検出し、即座に起動します）

  2. スタンドアロン実行ファイル（Python不要・単体起動）:
     -> 「dist\E57_PointCloud_Tool\E57_PointCloud_Tool.exe」
        （Python未インストールのPCでも直接ダブルクリックで動きます）

  3. 他のPCへツールを配る場合:
     -> 「dist\E57_PointCloud_Tool_Dist.zip」 を他PCへ送付・展開してください。

  4. Webブラウザ版ビューア:
     -> 「Webアプリ起動.bat」 をダブルクリックしてください。
        （ブラウザ上で点群ビューアが立ち上がります）


【フォルダ構成の一覧】
  ・ [core/]       : 点群処理・E57入出力・ノイズフィルタリングのコア処理
  ・ [gui/]        : 3Dビューア（OpenGL）、各種スライサー、メイン画面UI
  ・ [samples/]    : テスト・動作確認用のサンプル点群ファイル（.e57）
  ・ [tests/]      : 自動単体テスト・UI統合テストスイート
  ・ [dist/]       : スタンドアロンEXE実行フォルダおよび最新の配布用ZIP
      ├─ E57_PointCloud_Tool/     : スタンドアロンEXE一式
      ├─ E57_PointCloud_Tool_Dist.zip : 最新の配布用ZIPパッケージ
      └─ archive/                 : 過去バージョンのビルド退避フォルダ（安全保管）


【開発・保守ツール】
  ・ 「品質チェック実行.bat」
     -> 全5段階の品質管理ゲート（構文・ビューア不変条件・境界値・実機GUIシナリオ・単体テスト66件）を実行。
  ・ 「EXE配布パッケージ作成.bat」
     -> E57_PointCloud_Tool.spec からスタンドアロンEXEをビルドし、マニュアル同梱・旧ZIP退避・配布用ZIP生成を一括実行。
  ・ 「requirements-desktop.txt」 / 「requirements-lock.txt」
     -> デスクトップ版のPython必要パッケージ一覧（最小バージョン／動作確認済み固定バージョン）。
  ・ 「AGENTS.md」「CLAUDE.md」「AI_HANDOVER.md」「QA_REPORT_2026-10-31.md」
     -> 開発者・AI向け：並行開発ルール、設計憲章、品質管理チェック報告書。

【画面が変わった？ 元の画面に戻したいとき】
  ・ 2026-10 の改修で新UI（作業順のタブ・メニューバー・ステータスバー）になりました。
  ・ 改修前の画面に戻す: 画面上部「ヘルプ → 従来UIに戻す」 または 「設定 → システム → UIスタイル → 従来UI」
     （次回起動時に適用）。起動引数 --classic-ui、環境変数 E57_UI_MODE=classic でも可。
  ・ 新UIの配色は「設定 → システム → テーマ (新UI)」でダーク／軌跡（明るい地・黒い帯）をその場で切替（次回起動時も保持）。
     ボタンや通知の短いアニメーションは「設定 → システム → アニメーション」で OFF にできます。

【並行開発用フォルダ】
  ・ 「..\点群マイツール-claude」
     -> Claude 専用の git worktree（ブランチ claude/*）。このフォルダ（main）と同じ .git を共有。
        相手側のフォルダを直接編集せず、取り込みは git マージで行う（詳細は AGENTS.md）。
